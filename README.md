# DevBoard

**DevBoard** is a lightweight, local-first developer workspace designed to keep projects, notes and tools in one place.

It focuses on simplicity and everyday developer workflows, without the overhead of complex project management tools.

---

## ✨ Features

- 📊 Project & repository dashboard
- 📝 Markdown editor with live preview
- 📄 Export Markdown to PDF
- ✂️ Local code snippet manager
- ✅ Simple TODO tracker per project
- 🗒️ Notes for code review and development
- 🌙 Light / Dark theme

---

## 🧠 Philosophy

- Local-first
- No accounts, no cloud
- Minimal setup
- Developer-focused UX

---

## 🛠 Tech Stack

- React + TypeScript
- Vite
- (Planned) Tauri for desktop builds
- GitHub API (read-only)

---

## 🚧 Status

DevBoard is an early-stage personal project and is under active development.  
Features and structure may change.
